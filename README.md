# 👑 CodeHero Universe (1717)

> **Master ALL Programming Languages from Zero to Hero!**  
> An animated, interactive, kid-friendly coding universe with companion mascots, in-browser WebAssembly runtimes, Magic Memory Jars, and visual Detective "Why Did It Fail?" diagnostics.

---

## 🌟 Supported Languages & Companion Mascots

| Realm | Mascot Companion | Runtime Engine | Special Features |
| :--- | :--- | :--- | :--- |
| 🐍 **Python** | **Pythie the Dragon** | CPython 3.12 WebAssembly | Full standard library, 32 quests, memory jars |
| ⚡ **JavaScript** | **Sparky the Cyber Fox** | In-Browser Sandboxed JS | ES2024, Arrays, Objects, `console.log` |
| 🎨 **HTML & CSS** | **Pixie the Artist Cat** | Real-time DOM Frame | Live Web Preview, styles, buttons, layouts |
| 🗝️ **SQL** | **Shelldon the Vault Turtle** | In-Memory Relational DB | Structured Table Viewer (`SELECT`, `WHERE`, `ORDER BY`) |
| ⚙️ **C / C++** | **Geary the Clockwork Golem** | C Runtime & Memory Sim | `printf` formatting, types, memory visualization |
| ☕ **Java** | **Beany the Coffee Owl** | JVM Simulator | Classes, typed variables, `System.out.println` |
| 🦀 **Rust** | **Ferris the Friendly Crab** | Rust Borrow & Macro Sim | Immutability rules, `println!` macro formatting |

---

## ✨ Key Features

- **1-Click Language Switcher**: Jump between Python, JS, HTML, SQL, C, Java, and Rust seamlessly.
- **🕵️ "Why Did It Fail?" Detective**: Explains errors in plain 5th-grade English with side-by-side visual comparisons and a 1-click Auto-Apply fix.
- **🏺 Magic Memory Jars**: Visualizes variables as glowing potion jars on an alchemy shelf.
- **🌐 Live Web Preview & SQL Table Viewer**: Instant iframe rendering for HTML and tabular grid results for SQL queries.
- **🎵 Synthesized Web Audio**: Sound effects for wins, level ups, and clicks built entirely with Web Audio API (zero external audio files).
- **100% In-Browser Execution**: Zero backend server required. Runs completely client-side in modern browsers!

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/kalavalajohnlinnu-ui/codehero-1717.git

# Navigate into project
cd codehero-1717

# Install dependencies
npm install

# Start local server on port 1717
npm run dev -- --port 1717
```

Open `http://localhost:1717` in your browser!
